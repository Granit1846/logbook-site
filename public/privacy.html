Политика конфиденциальности LogBook

Дата публикации: 28 октября 2026 г.
Контакт владельца: jeriko1846@yandex.ru
Публичный адрес политики: https://granit1846.github.io/privacy.html

LogBook — электронная лётная книжка для экипажей вертолётов. Эта политика описывает обработку данных в Android-приложении.

Какие данные обрабатываются

Приложение хранит на устройстве введённые пользователем сведения о воздушных судах, полётах, экипажах, формулярах, ресурсах компонентов, маслах и техническом обслуживании. Для входа и синхронизации обрабатываются идентификатор учётной записи, адрес электронной почты при его использовании, сведения о привязке Telegram или MAX и токены сеанса. Пароль используется при входе по электронной почте; приложение не сохраняет его в локальном хранилище.

Для чего и куда передаются данные

Облачная синхронизация и вход выполняются через сервер Supabase, с которым приложение обменивается данными по HTTPS. При синхронизации на сервер передаются данные лётной книжки, необходимые для обмена между устройствами и связанными приложениями. При входе через Telegram или MAX пользователь подтверждает вход в соответствующем боте; приложение получает результат авторизации от сервера. Обмен с приложением для Windows по локальной сети выполняется после сопряжения с ПК.

После синхронизации через интернет данные профилей воздушных судов (бортовой номер, полёты с указанным составом экипажа, формуляры, ресурсы и журнал обслуживания) публикуются в общий каталог сервиса, чтобы другие члены экипажа могли загрузить профиль своего борта. Личные данные учётной записи (адрес электронной почты, идентификаторы Telegram и MAX, токены) в общий каталог не передаются.

Пользователь может самостоятельно сохранить резервную копию в выбранное им место или импортировать её. Приложение также создаёт локальные защитные копии перед восстановлением и синхронизацией. Системное резервное копирование Android может зависеть от настроек устройства и учётной записи Android.

Хранение и управление

Данные лётной книжки находятся в локальной базе приложения, а данные синхронизации — также на сервере при использовании облачной функции. Токены сеанса сохраняются на устройстве с использованием Android Keystore. Пользователь может удалить локальные данные средствами приложения или удалив приложение. Для вопросов об удалении данных учётной записи и серверной копии свяжитесь с владельцем по адресу выше.

Разрешения

Доступ к интернету нужен для авторизации и облачной синхронизации; доступ к локальной сети — для обмена с ПК; камера — для QR-сопряжения; уведомления и запуск после перезагрузки — для ежедневных предупреждений о ресурсах.

Реклама и статистика

В Android-приложении не используются рекламные и аналитические SDK.

Изменения политики

Актуальная версия политики будет размещена по адресу, указанному выше. Вопросы о работе с данными можно направлять на контактный адрес владельца.
